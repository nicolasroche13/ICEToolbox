# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.1]

### Added

- Figma-based ICE Toolbox application shell
- Light and dark themes
- Expandable/collapsible navigation sidebar
- Home, About and placeholder pages
- Bundled Inter Variable and JetBrains Mono fonts
- Packaged SVG icon resources
- Basic keyboard focus indication
- UI shell tests

### Fixed

- Application resources are now correctly included in packaged distributions

## [0.1.0]

### Added

- Initial project structure
- Basic PySide6 application
- Testing foundation
- GitHub Actions test workflow
